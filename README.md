# fmc-mcp-server

MCP server for **Cisco Secure Firewall Management Center (FMC)**, built on
[stutters-mcp-core](https://github.com/dr-stutters/stutters-mcp-core).

> Status: in development (milestone 1: scaffold). The full tool list, configuration table and
> deployment guide arrive with v0.1.0.

```bash
cp .env.example .env      # FMC_URL / FMC_USERNAME / FMC_PASSWORD
uv run fmc-mcp-server check
```
